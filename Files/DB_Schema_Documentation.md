# 🗄️ Database Schema Documentation

**For Frontend Developers**

This document details the Supabase PostgreSQL schema, including table structures, data types, and security policies (RLS).

---

## 🔒 Authentication & Users

### 1. `public.profiles`
**Purpose**: Extends the default `auth.users` table. Stores public user information and gamification stats.
*   **Trigger**: Automatically created when a user signs up.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. Matches `auth.users.id`. |
| `full_name` | `TEXT` | User's display name. |
| `avatar_url` | `TEXT` | URL to user's profile picture. |
| `current_streak` | `INT` | Current daily login/learning streak count. |
| `total_xp` | `INT` | Total experience points earned from quizzes/courses. |
| `last_active_date` | `DATE` | Last date the user was active (used for streak calculation). |
| `created_at` | `TIMESTAMPTZ` | When the user joined. |
| `updated_at` | `TIMESTAMPTZ` | Last update timestamp. |

## 📚 Course Content

### 2. `public.courses`
**Purpose**: Stores metadata for generated courses.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. Unique course ID. |
| `user_id` | `UUID` | **Foreign Key**. The owner of the course. |
| `title` | `TEXT` | Course title. |
| `description` | `TEXT` | Brief course description. |
| `difficulty` | `ENUM` | `Low`, `Medium`, `High`. |
| `course_type` | `ENUM` | `Interview`, `Basics`, `Deep Concepts`. |
| `toc` | `JSONB` | **The Table of Contents**. Contains the list of 15 chapters. generated by LLM. |
| `created_at` | `TIMESTAMPTZ` | Creation time. |
| `updated_at` | `TIMESTAMPTZ` | Last update timestamp. |

### 3. `public.chapters`
**Purpose**: Stores the actual learning content (slides & quizzes) for a specific chapter.
*   **Lazy Loading**: Content might be generated *after* the course is created. Check `is_generated`.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. |
| `course_id` | `UUID` | **Foreign Key**. Links to `public.courses`. |
| `chapter_index` | `INT` | The order of the chapter (1-15). |
| `title` | `TEXT` | Chapter title. |
| `content` | `JSONB` | **The Core Content**. Contains `slides` (array) and `quiz` (array). |
| `is_generated` | `BOOL` | `false` = Content pending generation. `true` = Ready to view. |
| `created_at` | `TIMESTAMPTZ` | Creation time. |
| `updated_at` | `TIMESTAMPTZ` | Last update timestamp. |

## 📈 User Progress & Learning

### 4. `public.user_course_progress`
**Purpose**: Tracks high-level progress for a course.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. |
| `user_id` | `UUID` | **Foreign Key**. |
| `course_id` | `UUID` | **Foreign Key**. |
| `status` | `ENUM` | `Yet To Start`, `In Progress`, `Completed`. |
| `last_accessed_at` | `TIMESTAMPTZ` | Used for "Continue Learning" sorting. |
| `updated_at` | `TIMESTAMPTZ` | Last update timestamp. |

### 5. `public.user_chapter_progress`
**Purpose**: Tracks distinct progress within a chapter (slides & quiz).

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. |
| `user_id` | `UUID` | **Foreign Key**. |
| `chapter_id` | `UUID` | **Foreign Key**. |
| `completed` | `BOOL` | `true` if chapter is finished. |
| `last_slide_index` | `INT` | **Resume Point**. 0-based index of the last viewed slide. |
| `quiz_score` | `INT` | Number of correct answers (usually out of 5). |
| `completed_at` | `TIMESTAMPTZ` | When it was finished. |
| `updated_at` | `TIMESTAMPTZ` | Last update timestamp. |

### 6. `public.daily_capsules`
**Purpose**: Stores personalized daily micro-learning content.

| Column | Type | Description |
| :--- | :--- | :--- |
| `id` | `UUID` | **Primary Key**. |
| `content` | `JSONB` | Array of flashcards or micro-lessons. |
| `date` | `DATE` | The specific date this capsule is for. |
| `is_completed` | `BOOL` | `true` if user finished the daily capsule. |

### 7. `public.user_skills`
**Purpose**: Stores the "Skill Map" data for visualization.

| Column | Type | Description |
| :--- | :--- | :--- |
| `skill_name` | `TEXT` | E.g., "Python", "System Design". |
| `level` | `INT` | proficiency score (0-100). |
| `updated_at` | `TIMESTAMPTZ` | Last updated. |

## 🛡️ Security Policies (RLS)

**General Rule**: Users can **only** access their **own** data.

| Table | Policy Summary |
| :--- | :--- |
| `profiles` | Users can view/edit ONLY their own profile (`auth.uid() = id`). |
| `courses` | Users can CRUD only courses where `user_id` matches their ID. |
| `chapters` | Users can Access chapters ONLY if they own the parent Course. |
| `user_..._progress` | Users can CRUD only their own progress records. |
| `daily_capsules` | Users can CRUD only their own daily capsules. |
| `user_skills` | Users can CRUD only their own skills. |
| `content_feedback` | Users can CRUD only their own feedback. |
| `user_bookmarks` | Users can CRUD only their own bookmarks. |

> [!NOTE]
> All tables have `enable row level security` turned on. Attempts to access other users' data will return an empty result set (for Select) or an error (for Insert/Update).
